# Sistema de Gestão Bancária em C / Bank Management System in C

Este projeto consiste num Sistema de Gestão Bancária desenvolvido em linguagem C, que utiliza listas ligadas (listas simplesmente encadeadas) para armazenar e gerir informações de clientes de um banco de forma dinâmica.
O sistema permite realizar operações bancárias básicas, como cadastro de clientes, consulta de dados, depósitos, levantamentos, remoção de clientes e salvamento de dados em ficheiro, tudo através de um menu interativo em consola. 

Funcionalidades Principais:
- Autenticação por PIN: O acesso ao sistema é protegido por uma palavra-passe numérica (PIN).
- Adicionar clientes: Criação de novos clientes com ID, nome e saldo inicial.
- Exibir lista de clientes: Mostra todos os clientes cadastrados no sistema.
- Buscar cliente por ID: Permite localizar um cliente específico.
- Remover cliente: Remove um cliente da lista ligada com base no ID.
- Depositar dinheiro: Adiciona um valor ao saldo do cliente.
- Sacar dinheiro: Permite levantar valores, verificando saldo suficiente.
- Consultar saldo: Exibe o saldo atual de um cliente.
- Salvar dados em arquivo: Guarda os dados dos clientes num ficheiro de texto (.txt ou .csv).
- Libertação de memória: Toda a memória alocada dinamicamente é libertada ao encerrar o programa.



This project is a Bank Management System developed in the C programming language, using singly linked lists to dynamically store and manage bank customer data.
The system provides basic banking operations such as client registration, data consultation, deposits, withdrawals, client removal, and saving data to a file, all through an interactive console menu.

Main Features
- PIN authentication: Access to the system is protected by a numeric password (PIN).
- Add customers: Create new customers with ID, name, and initial balance.
- Display customer list: Shows all customers registered in the system.
- Search for customer by ID: Allows you to locate a specific customer.
- Remove customer: Removes a customer from the linked list based on their ID.
- Deposit money: Adds an amount to the customer's balance.
- Withdraw money: Allows you to withdraw amounts, checking that there is sufficient balance.
- Check balance: Displays a customer's current balance.
- Save data to file: Saves customer data to a text file (.txt or .csv).
- Memory release: All dynamically allocated memory is released when the program is closed.
